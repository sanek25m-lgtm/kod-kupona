How to check a promo code before payment

Check at checkout

  1. Open the store and add eligible products.
  2. Check expiry, minimum spend, categories and customer eligibility.
  3. Enter the code in the appropriate field without extra spaces.
  4. Click Apply and read the store's response.
  5. Check the final total immediately before paying.

If the code did not work

Check restrictions and try again only after resolving them.

The date in the affiliate feed — this is source information, not proof that the code was tested in your cart.

The terms and conditions are translated automatically. Check the terms and conditions on the store's website.
